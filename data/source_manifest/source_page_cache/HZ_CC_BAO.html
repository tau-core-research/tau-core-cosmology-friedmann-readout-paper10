Cosmic Chronometers data

The current dataset do not provide a full covariance matrix as discussed in Moresco et al. (2020). In order to use CC data, the covariance matrix has to be added following the recipes provided in that paper. An example on how to do that is given in the gitlab page assosciated to the arXiv repository of the paper.

When using these dataset, please add the proper reference, as indicated in the table.
