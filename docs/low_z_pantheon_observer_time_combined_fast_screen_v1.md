# Low-z Pantheon observer/time combined fast screen v1

**Doc class:** source-frozen diagnostic fast screen
**Status:** preauthorization, not replay, not validation
**Canonical parent:** Paper 10 README and manuscript

This screen tests whether the already frozen narrow observer/path carrier and
the already frozen narrow CC-uncertainty `W_time` basis have useful overlap on
the 12-row observer-basis scope.

The screened families are:

- `observer_only`: the current authorized observer-basis carrier
  `W_path * sky_x * z_centered`;
- `time_on_observer_scope`: the `W_time_uncertainty_basis` restricted and
  renormalized on the same 12-row scope;
- `observer_times_time`: multiplicative observer/time coupling;
- `observer_plus_time`: normalized additive observer/time proxy.

The result is not an endpoint replay and does not authorize a validation claim.
It is only a decision aid for whether a later external reviewer package should
be prepared for a combined observer/time channel.
