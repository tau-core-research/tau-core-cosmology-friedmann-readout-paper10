# Void/Web Source-Native Frozen Products V1

This artifact freezes the first source-native void/web products for Paper 10:

```text
data/source_manifest/void_web_source_native_frozen_products_v1.csv
```

It is generated by:

```bash
python scripts/acquire_void_web_source_native_products_v1.py
python scripts/validate_void_web_source_native_products_v1.py
```

## Frozen Products

The void side freezes two VAST/SDSS DR7 Planck2018 files:

- `VoidFinder-nsa_v1_0_1_Planck2018_comoving_maximal.txt`
- `NSA_main_mask.pickle`

The web side freezes two SDSS DR17 MCPM files:

- `slimeMold_galaxy_catalog_v1_0_1.fits`
- `eboss_lss_mcpm_v1_0_1.sha1sum`

## Endpoint Status

All rows remain:

```text
SOURCE_NATIVE_PRODUCT_FETCHED_FROZEN
endpoint_allowed=false
```

This is intentional. The files are now source-native and checksum-locked, but
their transformation into endpoint-ready `W_void` and `W_web` columns is not
yet frozen.

## Remaining Gate

Before endpoint scoring, a future transform manifest must define:

- void redshift/radius summaries and maturity bins,
- web density or environment summaries,
- survey-mask and sample-selection rules,
- mappings from catalogue coordinates/redshifts to cosmology scoring rows,
- null controls,
- and covariance/scope policy for any multi-probe score.

Until that gate is passed, the current `W_void + W_web` run remains a
proxy-only full-covariance scoring-grammar stress test.
