# V2 Observer-Basis Candidate Review

The fast observer-basis screen found a stronger source-side candidate:

```text
W_path_x_sky_x_x_zcenter
```

This package asks an external reviewer to decide whether that candidate may be
promoted to a separate permission-only replay authorization package.

The reviewer must check:

1. the family was predeclared in the fast screen,
2. it uses only source-side values (`W_path`, `sky_x`, and centered `zHD`),
3. it is not selected from endpoint residuals or distance residuals,
4. the screen result is not over-read as validation,
5. any next step remains a separate permission-only replay authorization.

The reviewer should not approve endpoint validation or physical lensing-path
weight claims.
